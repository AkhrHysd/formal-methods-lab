# 第002回の演習

同じ人物、商品、ポイント取引について考える。TypeScript の `balance`（保有ポイント数）と `usage`（利用ポイント数）は非負の安全な整数とする。保有ポイントで全額をまかなえるときに利用を許可する。

## 自然言語（3分）

次の命題の否定を自然な日本語で書く。年齢がちょうど18歳、在庫数がちょうど0、利用数と保有数が同じ場合を使い、元の命題と否定の真偽を照合する。

1. 年齢は18歳以上である。
2. 在庫数は0である。
3. 利用ポイント数は保有ポイント数より大きい。

## TypeScript（7分）

1. [実装ファイル](../../typescript/exercises/002-negation/negation.ts)の `isUsageDenied` は、利用を許可する条件を否定演算子 `!` で反転する。第001回の条件を考え直し、このファイル内で実装する。
2. 同じファイルの `isUsageDeniedDirect` は、比較演算子のみで利用を拒否する条件を書く。
3. [テストファイル](../../typescript/exercises/002-negation/negation.test.ts)の5ケースについて、仕様から期待値を決める。両関数を個別に呼び、各結果をその期待値と照合する assertion を書いて、未実装の例外を置き換える。

## Lean（5分）

1. [Lean ファイル](../../lean/Exercises/L002Negation.lean)で `#check (!(1 == 2))` と `#check (¬ (1 = 2))` を試し、それぞれの型を記録する。`#eval (!(1 == 2))` と `#eval (decide (¬ (1 = 2)))` を試し、表示された値と `decide` の役割を説明する。
2. `threeNotFour` と `sevenNotZero` の `sorry` を自分の証明に置き換える。手が止まったら、等式を仮定した直後に InfoView で仮定とゴールを読む。
3. 任意の実験として、登録ファイルとは別の手元の確認用ファイルで `¬ (3 = 3)` を証明しようとし、なぜゴールを閉じられないか考える。

### 次の命題について、否定した命題を自然言語と数式の両方で書いてください。

#### 問題	元の命題

- A-1	ユーザーの年齢は18歳以上である
  
- A-2	在庫数は0である
- A-3	利用ポイント数は保有ポイント数より大きい

### A-1

- 元の命題： ユーザーの年齢は18歳以上である
- 否定した命題（自然言語）： ユーザーの年齢は18歳以上ではない
- 否定した命題（数式）： A !>= 18

### A-2

- 元の命題： 在庫数は0である
- 否定した命題（自然言語）： 在庫数は0ではない
- 否定した命題（数式）： S !== 0


### A-2

- 元の命題： 利用ポイント数は保有ポイント数より大きい
- 否定した命題（自然言語）： 利用ポイント数は保有ポイント数より大きくない
- 否定した命題（数式）： A !>= B
